How the simulation works

Every invoice, amount and exception is the same in both scenarios; only the process rules change. AS-IS: manual matching (1–4 working days), exceptions resolved by email (4–15 days), approvals with no reminder (2–14 working days), a weekly payment list where 12% of invoices are missed for a week, and half of duplicate invoices caught. TO-BE: automatic three-way match for clean invoices, an exception queue with an owner (1–5 working days, 10% real supplier disputes of 10–25 days), a 3-day approval SLA with reminders (15% still late), payment runs scheduled on due dates, and 90% of duplicates blocked.

These are assumptions for discussion, not measured results. Data generated with a fixed seed; see the dataset README.
