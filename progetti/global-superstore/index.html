01

OVERVIEW

Project overview

This case study examines a cleaned Global Superstore dataset and presents the analysis through an interactive browser dashboard. The focus is sales and profitability across time, markets, categories, sub-categories and discount levels.

02

SCOPE

Business questions

  • Which markets and categories generate the most sales?
  • Which markets and categories generate the most profit?
  • What is the overall profit margin?
  • Which sub-categories reduce profitability?
  • How are discount levels associated with profit?
  • Which sales lines generate losses?
  • How can the dashboard support further investigation?
03

DATA

Dataset and context

The dashboard reads orders_clean.csv, containing 51,290 rows dated 2011–2014. Relevant fields include order date, market, category, sub-category, sales, profit and discount. Figures on this page use the full dataset with no dashboard filters applied.

04

ANALYSIS

How the analysis was structured

The work moves from overall sales, profit and margin to comparisons by market, category and sub-category, then to discount bands and loss-making sales lines. A separate SQL script contains supporting category, Furniture sub-category and Tables discount analyses. SQL is not part of the dashboard implementation: the web app reads the CSV and calculates interactive views in JavaScript.

05

DATA CHECKS

How the data was checked

The SQL analysis file includes queries to compare row and order identifiers, review date ranges and date types, and identify product IDs associated with multiple names or sub-categories. These checks are documented in the script; this case study does not claim that every query was run against a live database.

The dashboard loads the cleaned CSV directly. Its headline totals were separately recalculated from that file and checked against the unfiltered dashboard values. The SQL script expects a PostgreSQL public.orders table and includes an ALTER TABLE date conversion; use a test copy before running that statement.

06

DASHBOARD

Dashboard design

The dashboard is built with HTML, CSS and JavaScript. It reads the CSV in the browser and has three views: Executive Overview, Profitability Diagnostics and Discount Intelligence. Date, market, category and sub-category filters update the visible results.

Charts compare monthly sales and profit, category and market profit, sub-category performance and discount bands. A table lists loss-making sales lines for investigation.

07

VALIDATION

KPIs and validation

  • Total sales$12,642,501.91
  • Total profit$1,467,457.29
  • Profit margin11.61% (total profit ÷ total sales)

The CSV totals match the dashboard's unfiltered KPIs. Profit margin is calculated as aggregate profit divided by aggregate sales, not as the average of row-level margins.

08

OBSERVATIONS

Main observations

Observed in the dataset

  • 01

    APAC records the highest market sales ($3,585,744.13) and profit ($436,000.05).

  • 02

    Technology has the highest category sales ($4,744,557.50) and profit ($663,778.73).

  • 03

    Tables is the only sub-category with negative aggregate profit: −$64,083.39.

  • 04

    Sales lines with discounts of 30% or more total $1,736,588.11 in sales and −$813,212.32 in profit.

Possible interpretation

Tables and the highest discount band are useful starting points for further review. These aggregate results do not explain why the losses occurred.

09

LIMITS

Limitations

  • The data covers 2011–2014 and does not describe current performance.
  • Aggregate comparisons do not control for product mix, order size, customer type, costs or other variables.
  • The observed discount-profit relationship is descriptive; it does not establish that discounts caused lower profit.
10

NEXT QUESTIONS

Possible next questions

  • Which Tables products and markets account for the sub-category's losses?
  • Does the high-discount pattern remain when comparing similar products and markets?
  • What cost, promotion and customer data would help explain the differences?
  • Which segments should be prioritised for a deeper review with business stakeholders?
